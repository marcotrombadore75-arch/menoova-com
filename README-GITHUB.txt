1. Carica index.html, assets/ e CNAME nella root del repository.
2. In Settings > Pages seleziona Deploy from a branch e la branch principale / root.
3. Il file CNAME contiene cassaiq.com. Se il dominio è gestito diversamente, puoi rimuoverlo.
4. La pagina usa link relativi privacy.html e termini-condizioni.html: se nel repository esistono già, lasciali. Altrimenti carica anche le pagine legali prima della pubblicazione definitiva.
